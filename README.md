# React Toast Manager

A lightweight, customizable, and persistent React toast notification manager. Easily display various types of notifications to your users without unnecessary complexities.

## ✨ Features

* **Chaining API:** Fluent and intuitive API allows you to chain multiple configuration methods before displaying a toast.
* **Customizable Types:** Supports default, success, warning, and info toast types.
* **Flexible Styling:** Easily set background colors and duration.
* **Interactive Toasts:** Attach `onClick` handlers to toasts.
* **Smooth Animations:** Configurable entry/exit animations.
* **Persistent:** Toasts don't automatically disappear unless a duration is set.
* **Error Boundary:** Includes an `ErrorBoundary` component for robust application usage, catching React component errors.

## 📦 Installation

To install `react-toast-manager` in your React project, use npm or yarn:

```bash
npm install react-toast-manager
# or
yarn add react-toast-manager
